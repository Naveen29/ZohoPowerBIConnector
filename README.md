# Zoho Power BI Connector Portal

This repository contains the scaffold for the Zoho to Power BI Connector portal project.

## Project Structure

- `WebAPI` - ASP.NET Core 8 Web API backend
- `Database` - SQL Server schema and scripts
- `Frontend` - Public website and customer portal frontend
- `Documentation` - Legal pages and product docs
- `Deployment` - Deployment configuration and production checklist

## Next steps

1. Initialize the ASP.NET Core Web API project in `WebAPI`.
2. Add SQL Server scripts and schema to `Database`.
3. Build the public website in `Frontend`.
4. Add documentation pages in `Documentation`.
5. Add deployment and hosting guidance in `Deployment`.
