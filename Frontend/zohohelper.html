Zoho Helper

Follow this step-by-step guide to create your Zoho Client ID, Client Secret, Refresh Token, and Organization ID.

What You Need

Before you begin, make sure you have access to your Zoho account and can sign in to the Zoho API Console.

  • Client ID
  • Client Secret
  • Refresh Token
  • Organization ID

Step 1: Create a Self Client

Open the Zoho API Console and create a new self client. A self client is the recommended method for connector authentication because it does not require a redirect URI.

  1. Go to https://api-console.zoho.com/.
  2. Sign in with your Zoho account.
  3. Click Add Client.
  4. Select Self Client.
  5. Click Create and open the newly created Self Client.

Copy and save:

  • Client ID
  • Client Secret

Step 2: Generate a Grant Token

Inside your Zoho Self Client, generate a one-time grant token for the ZohoBooks.fullaccess.all scope.

Use a short validity period such as 10 minutes, then click Create.

Important: The grant token is one-time use only and expires after the selected validity period.

Example token format:

1000.xxxxxxxxxxxxxxxxxxxxxxxxx

Step 3: Generate the Refresh Token

Use a POST request to generate the refresh token using your client credentials and the grant token.

Request URL:

https://accounts.zoho.com/oauth/v2/token

Body type: x-www-form-urlencoded

Parameter Value
grant_type authorization_code
client_id Your Client ID
client_secret Your Client Secret
code Your Grant Token

Example response:

{
  "access_token": "1000.xxxxxxxxx",
  "refresh_token": "1000.xxxxxxxxx",
  "expires_in": 3600
}

Save the refresh_token. Your connector uses it to request new access tokens automatically.

Step 4: Find Your Organization ID

Use the access token from the previous step to fetch your organization information.

Request URL:

https://www.zohoapis.com/books/v3/organizations

Header:

Authorization: Zoho-oauthtoken YOUR_ACCESS_TOKEN

Sample response:

{
  "organizations": [
    {
      "organization_id": "1234567890",
      "name": "ABC Company"
    }
  ]
}

Copy the organization_id value.

Connector Credentials

Enter these values into the Zoho configuration page in your connector:

  • Client ID
  • Client Secret
  • Refresh Token
  • Organization ID
Setup Complete!

Your Zoho Books account is now ready to connect with the Zoho Power BI Connector.
